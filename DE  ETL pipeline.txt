An **ETL (Extract, Transform, Load) pipeline** is a process used to collect data from different sources, clean and transform it, and load it into a destination such as a data warehouse for reporting and analytics.

### 1. ETL Pipeline

The ETL process consists of three main stages:

* **Extract**

  * Collect data from multiple sources such as databases, APIs, CSV files, cloud storage, and applications.
  * Example: Extract customer data from a MySQL database.

* **Transform**

  * Clean, validate, standardize, and enrich the data.
  * Operations include:

    * Removing duplicates
    * Handling missing values
    * Data type conversion
    * Joining multiple datasets
    * Business rule implementation

* **Load**

  * Store the transformed data into a target system like a data warehouse or data lake.
  * Loading can be:

    * Full Load
    * Incremental Load

**Example Flow:**

```
Source Systems
(MySQL, CSV, APIs)
        │
        ▼
     Extract
        │
        ▼
    Transform
(Clean, Join, Validate)
        │
        ▼
       Load
        │
        ▼
Data Warehouse
```

## 2. Databases vs Data Warehouses

| Database                                      | Data Warehouse                                        |
| --------------------------------------------- | ----------------------------------------------------- |
| Stores current operational data               | Stores historical and analytical data                 |
| Used for day-to-day transactions              | Used for reporting and business intelligence          |
| Optimized for inserts, updates, deletes       | Optimized for complex queries                         |
| Supports OLTP (Online Transaction Processing) | Supports OLAP (Online Analytical Processing)          |
| Examples: MySQL, PostgreSQL, Oracle           | Examples: Snowflake, Amazon Redshift, Google BigQuery |

### Database

* Stores live business data.
* Example:

  * Banking transactions
  * Customer records
  * Orders

### Data Warehouse

* Combines data from multiple databases.
* Used for:

  * Dashboards
  * Reporting
  * Analytics
  * Machine Learning

## 3. Big Data Technologies

### Apache Spark

* Fast distributed data processing engine.
* Processes large datasets in memory.
* Supports:

  * SQL
  * Machine Learning
  * Streaming
  * Graph processing

**Advantages**

* Very fast
* Fault tolerant
* Supports Python (PySpark), Scala, Java, SQL

---

### Apache Hadoop

Framework for storing and processing massive datasets.

Main components:

**HDFS (Hadoop Distributed File System)**

* Distributed storage across multiple machines.

**YARN**

* Resource management.

**MapReduce**

* Distributed batch processing.

Suitable for:

* Petabytes of data
* Batch processing
* Distributed storage

---

### Apache Kafka

A distributed event streaming platform.

Uses:

* Real-time data streaming
* Log aggregation
* Messaging
* IoT applications

Example:

```
Application
      │
Producer
      │
Kafka Topics
      │
Consumer
      │
Spark / Database / Dashboard
```

Features:

* High throughput
* Fault tolerant
* Scalable
* Real-time processing

## 4. Data Integration

**Data Integration** is the process of combining data from different sources into a unified view.

### Sources

* Databases
* APIs
* CSV/Excel files
* Cloud storage
* ERP systems
* CRM systems

### Integration Process

```
Multiple Sources
      │
      ▼
Data Integration
      │
(Clean + Transform)
      │
      ▼
Data Warehouse
      │
      ▼
BI Reports / Analytics
```

### Benefits

* Single source of truth
* Better decision-making
* Improved data quality
* Consistent reporting

### Interview Summary

* **ETL Pipeline:** Extracts, transforms, and loads data into a target system.
* **Database:** Stores operational, transactional data (OLTP).
* **Data Warehouse:** Stores integrated historical data for analytics (OLAP).
* **Apache Spark:** Fast distributed processing engine for batch and streaming data.
* **Apache Hadoop:** Distributed storage and batch processing framework.
* **Apache Kafka:** Real-time event streaming and messaging platform.
* **Data Integration:** Combines data from multiple sources into a unified, consistent dataset for analysis.
